# Company Culture and Financial Performance Dataset

This repository contains the public sharing files for the company-level dataset
used in the Company Culture and Financial Performance analysis.

## Files

- `company_level_data.csv`: company-level analysis dataset with culture scores,
  listing status, pre-period controls, forward financial outcomes, and related
  publication-safe firm controls.
- `data_dictionary.csv`: field-level documentation for the dataset, including
  source table, category, description, and notes.

## Dataset Shape

- Unit of observation: company
- Rows: 889
- Format: CSV

The dataset includes company identifiers such as stock tickers and public-listing
status, plus standardized culture dimensions and financial-performance fields.
See `data_dictionary.csv` for variable definitions.
